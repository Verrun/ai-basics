# GitHub-проекты для web research

Подборка open-source инструментов для **М6**. Не обязательно устанавливать — достаточно изучить README.

---

## Как искать на GitHub

```
awesome ai search
web scraping llm
research agent mcp
gpt researcher
perplexica
```

**На что смотреть:**
- ⭐ Stars (популярность)
- 📅 Последний коммит (активность)
- 📖 README на понятном языке
- 🔌 Есть ли MCP / Cursor integration

## Когда GitHub-проект vs готовый MCP

| Ситуация | Выбор |
|----------|-------|
| Быстро начать в Cursor | Firecrawl / Tavily MCP (plugin) |
| Нужен полный контроль, self-host | GPT Researcher, Perplexica |
| Прочитать один PDF | MarkItDown MCP |
| Простой research с ссылками | Perplexity (не GitHub) |
