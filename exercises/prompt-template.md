# Шаблон хорошего промпта

Используй для практики в **М2** и дальше по курсу.

---

## Слабый промпт (исходник)

```
Напиши пост про кофе
```

**Проблемы:** нет роли, формата, контекста, ограничений.

---

## Шаблон (заполни своими данными)

```
Роль: Ты [профессия/роль, например: SMM-менеджер кофейни].

Задача: [что сделать, например: напиши пост для Instagram].

Контекст: [фон, например: кофейня в бизнес-центре, аудитория — офисные работники 25–40 лет].

Формат: [объём, структура, например: 100 слов, 3 коротких абзаца, 1–2 эмодзи].

Ограничения: [чего избегать, например: без слова "уникальный", тон дружелюбный, призыв зайти на обед].
```

---

## Твой вариант (заполни)

**Тема:** _______________________

```
Роль:

Задача:

Контекст:

Формат:

Ограничения:
```

---

## Проверка

- [ ] Есть все 5 частей?
- [ ] Задача конкретная (не «напиши что-нибудь»)?
- [ ] Формат измеримый (слова, абзацы, список)?
- [ ] Ограничения помогают, а не душат?

---
