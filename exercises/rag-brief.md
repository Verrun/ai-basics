# Бриф: мини-RAG без кода

Практика для **М6b**.

Цель: почувствовать разницу между ответом «из головы» модели и ответом **по твоим документам**.

---

## Подготовка (10 мин)

Собери **3–5 коротких текстов** (без паролей, ПДн, коммерческой тайны):

- [ ] FAQ продукта / сервиса (можно вымышленный)
- [ ] Правила: дедлайны, «как оформить отпуск», «куда писать баг»
- [ ] Выдержка из гайда или своей заметки Obsidian

Положи их в одну папку или в vault Obsidian.  
Или загрузи в **Projects / Knowledge** чата (ChatGPT / Claude) — что доступно.

**Вопрос одной строкой** (запиши заранее):

> _______________________________________________

Пример: «Какой дедлайн сдачи отчёта и куда его отправлять?»

---

## Эксперимент A — без документов

1. Открой обычный чат (без файлов / без vault).
2. Задай тот же вопрос.
3. Запиши ответ и отметь:

| | Да / Нет |
|--|----------|
| Есть конкретные цифры/имена? | |
| Указан источник? | |
| Могла ли модель это выдумать? | |

---

## Эксперимент B — с документами

Выбери **один** способ:

- [ ] Прикрепить файлы к чату / загрузить в Knowledge
- [ ] Cursor: открыть папку с текстами → Agent → тот же вопрос + «отвечай только по файлам в проекте, цитируй путь»
- [ ] Obsidian MCP: «найди в vault и ответь со ссылкой на заметку»

| | Да / Нет / Что именно |
|--|------------------------|
| Ответ опирается на твои тексты? | |
| Есть цитата / имя файла? | |
| Совпало с тем, что в документе? | |
| Добавила ли модель «от себя»? | |
