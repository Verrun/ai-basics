## Секция 2: Basics (6 слайдов)

### S04 — Что такое LLM
**Термин:** LLM (Large Language Model)  
**Аналогия:** *очень умное автодополнение*  
**Буллеты:**
- Предсказывает следующее слово
- Не «знает факты» — собирает правдоподобный текст
- ChatGPT, Claude, Gemini — все LLM
**Notes:** Главная мысль: AI не база данных. Он генерирует текст.

### S05 — Что AI умеет
**Заголовок:** Когда AI помогает  
**Буллеты:**
- Тексты, идеи, черновики
- Перевод и пересказ
- Структурирование информации
- Прототипы и исследования
**Notes:** AI — помощник, не замена эксперта.

### S06 — Что AI не умеет
**Заголовок:** Лимиты AI  
**Буллеты:**
- Гарантировать правду (галлюцинации)
- Знать события после даты обучения
- Брать ответственность за решения
**Notes:** Всегда проверяй факты.

### S07 — Галлюцинации
**Термин:** Галлюцинация  
**Аналогия:** *уверенный собеседник, который выдумывает цитату*  
**Буллеты:**
- AI может назвать несуществующий факт
- Звучит убедительно — это опасно
- Решение: проверять по источникам
**Notes:** Пример: выдуманная дата, несуществующая статья.

### S08 — Конфиденциальность
**Заголовок:** Безопасность данных  
**Буллеты:**
- Не вставляй пароли и персональные данные
- Корпоративные секреты — только в разрешённых инструментах
- Читай политику сервиса
**Notes:** «Бесплатно» часто означает «данные могут использовать для обучения».

### S09 — Практика М1
**Заголовок:** Попробуй сама  
**Буллеты:**
- 3 вопроса AI: факт / творчество / «не знаю»
- Сравни уверенность ответов
- Отметь, где нужна проверка
**Notes:** Переход к модулю 2 — модели и промпты.

## Секция 4: Harness (5 слайдов)

### S17 — Что такое Harness
**Термин:** Harness  
**Аналогия:** *коробка с инструментами и правилами вокруг AI*  
**Буллеты:**
- Модель + инструменты + правила + лимиты
- Без harness — один ответ и всё
- С harness — AI действует в системе
**Notes:** Harness — не промпт. Это инфраструктура.

### S18 — Компоненты Harness
**Заголовок:** Из чего состоит  
**Буллеты:**
- **Инструменты** — файлы, браузер, поиск (MCP)
- **Правила** — что можно и нельзя
- **Песочница** — безопасная зона
- **Лог** — что AI делал
**Notes:** Схема: модель → harness → действие.

### S19 — Примеры Harness
**Заголовок:** Без кода  
**Буллеты:**
- AI + калькулятор (точные цифры)
- AI + файлы (читает документы)
- AI только читает, не пишет
**Notes:** Harness решает, какие «руки» у AI.

### S20 — Cursor Harness
**Заголовок:** Cursor: Agent · Rules · Skills  
**Буллеты:**
- **Agent mode** — AI сам выбирает действия
- **Rules** — постоянные инструкции
- **Skills** — чеклисты для задач
**Notes:** Это harness в Cursor.

### S21 — Практика М3
**Заголовок:** Заполни чеклист  
**Буллеты:**
- exercises/harness-checklist.md
- Определи инструменты, правила, лимиты для своей задачи

## Секция 5: MCP (7 слайдов)

### S22 — Что такое MCP
**Термин:** MCP (Model Context Protocol)  
**Аналогия:** *USB-порт для AI — один формат, много устройств*  
**Буллеты:**
- Стандарт подключения AI к сервисам
- Поиск, Figma, браузер, Obsidian
**Notes:** MCP — часть harness.

### S23 — MCP vs Plugin vs CLI
**Заголовок:** Три способа подключить инструмент  
**Буллеты:**
- **Plugin** — один клик в Cursor Marketplace
- **MCP** — разъём в Settings → MCP (часто внутри — CLI)
- **CLI** — команды в терминале; Agent запускает за тебя
**Notes:** GUI vs разъём vs текстовые команды. CLI учить наизусть не нужно.

### S24 — MCP для Research
**Заголовок:** Поиск в интернете  
**Буллеты:**
- **Firecrawl** — поиск, скрейп (обязательно)
- **MarkItDown** — PDF → текст
- **Context7** — актуальная документация
- **Tavily, Browser** — дополнительно
**Notes:** Perplexity — отдельный сервис, не MCP.

### S25 — MCP для Design
**Заголовок:** Дизайн и прототипы  
**Буллеты:**

### S26 — Obsidian-стек

**Notes:** Связка: план → vault → поиск по заметкам.

### S27 — Установка MCP
**Заголовок:** Как подключить  
**Буллеты:**
- Plugins: Firecrawl, Figma, Context7, Obsidian
- MCP вручную: MarkItDown, Chrome DevTools, Plannotator

## Секция 6: Loops (7 слайдов)

### S29 — Что такое Loop
**Термин:** Loop  
**Аналогия:** *повар пробует → добавляет → пробует снова*  
**Буллеты:**
- Подумал → Сделал → Посмотрел → Решил
- Не один ответ — цикл до готовности
**Notes:** Loop — внутри harness.

### S30 — Loop engineering
**Термин:** Loop engineering  
**Аналогия:** *правила игры: сколько попыток, кто проверяет*  
**Буллеты:**
- Когда продолжать
- Когда остановиться
- Как проверить результат
**Notes:** Отдельная дисциплина от harness.

### S31 — ReAct
**Термин:** ReAct (Reason + Act)  
**Буллеты:**
- Reason — AI думает
- Act — AI действует (tool call)
- Observe — смотрит результат
- Repeat — повторяет или стоп
**Notes:** Классический паттерн agent loop.

### S32 — Maker / Checker
**Заголовок:** Два участника  
**Буллеты:**
- **Maker** — создаёт результат
- **Checker** — проверяет по фактам
- Не «мне кажется готово» — независимая проверка
**Notes:** Checker может быть человек или другой AI.

### S33 — Лимиты и стоп
**Заголовок:** Когда остановиться  
**Буллеты:**
- Max попыток (например, 5)
- Стоп-условие («найдено 3 источника»)
- Эскалация к человеку
**Notes:** Без лимитов AI может крутиться бесконечно.

### S34 — Cursor /loop
**Заголовок:** Loop в Cursor  
**Буллеты:**
- `/loop 5m проверь статус` — AI возвращается через 5 мин
- Automations — повторяющиеся задачи
**Notes:** Loop engineering в действии.

### S35 — Практика М4
**Заголовок:** Сценарий maker/checker  
**Буллеты:**
- exercises/loop-scenario.md
- 4 шага с точкой проверки
**Notes:** Quiz: где нужен loop, где достаточно одного ответа.
