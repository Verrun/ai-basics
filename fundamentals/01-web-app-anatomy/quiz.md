# Quiz — Ф1. Как устроено приложение: фронтенд, бекенд, API и база данных

**Порог:** ≥80% (7 из 8 правильных)

---

## Вопросы

### 1. В аналогии с рестораном frontend («лицо» сайта) — это:

- [ ] A) Кухня, где готовят заказ
- [ ] B) Склад с продуктами
- [ ] C) Зал, меню и стол, за которым сидит гость
- [ ] D) Официант, который носит заказы

### 2. API по аналогии с рестораном — это:

- [ ] A) Программа, которая хранит все данные
- [ ] B) Договорённость (как официант с меню), какими словами можно «заказать» и в каком виде получить ответ
- [ ] C) Красивый экран с кнопками
- [ ] D) Сервер, на котором всё крутится

### 3. Чем база данных отличается от папки с файлами?

- [ ] A) Ничем — это синонимы
- [ ] B) База данных хранит только картинки
- [ ] C) Специальная программа, которая умеет быстро искать и связывать миллионы записей, а не просто хранить документы
- [ ] D) Папка работает быстрее базы данных

### 4. Клик по кнопке «Купить» — это:

- [ ] A) Одно действие в браузере
- [ ] B) Запрос сразу в базу данных, минуя сервер
- [ ] C) Цепочка: кнопка → API → бекенд → база данных → ответ → обновление экрана
- [ ] D) Действие, которое никак не связано с сервером

### 5. Backend («кухня») — это:

- [ ] A) Всё, что ты видишь на экране
- [ ] B) Договор о том, как обмениваться данными
- [ ] C) Программа на сервере, которая проверяет правила, считает и решает — но которую пользователь не видит
- [ ] D) Место, где хранятся все данные приложения

### 6. Endpoint (эндпоинт, «окошко выдачи») — это:

- [ ] A) Конкретный адрес API для конкретного дела: `/users`, `/orders`
- [ ] B) Кнопка на сайте
- [ ] C) Название базы данных
- [ ] D) Главная страница сайта

### 7. Если закрыть вкладку браузера, твои письма не исчезают, потому что:

- [ ] A) Frontend хранит копию всех данных
- [ ] B) Браузер сам всё запоминает навсегда
- [ ] C) Данные живут на сервере и в базе данных, а frontend только показывает их копию
- [ ] D) Письма пересылаются тебе на компьютер

### 8. Кнопка на сайте выглядит красиво и нажимается, но «ничего не происходит». Наиболее вероятно:

- [ ] A) Проблема точно в твоём мониторе
- [ ] B) Где-то за кадром (API, backend или база) не отвечает — красивый экран не гарантирует рабочую логику
- [ ] C) Красивые кнопки никогда не ломаются
- [ ] D) Значит, сайт не имеет frontend

---

## Ключ ответов

1. **C** — Зал и меню: то, что видит и трогает пользователь
2. **B** — API — договор обмена, а не программа или экран
3. **C** — БД — программа для быстрого поиска и связей, а не коробка с файлами
4. **C** — Один клик = целая цепочка через API, бекенд и базу
5. **C** — Backend прячется на сервере и думает за кадром
6. **A** — Endpoint — конкретное «окошко» API с адресом
7. **C** — Хранит сервер и база данных, frontend всё «забывает»
8. **B** — Поломка может быть на любом шаге цепочки, не только «на картинке»
