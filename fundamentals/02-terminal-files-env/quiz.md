# Quiz — Ф2. Терминал, файлы, зависимости и переменные окружения

**Порог:** ≥80% (7 из 8 правильных)

---

## Вопросы

### 1. Терминал — это:

- [ ] A) Программа для взлома, которую используют хакеры
- [ ] B) Кнопки и окна вместо текста
- [ ] C) Окно, куда вводят текстовые команды — как пульт управления домом по SMS
- [ ] D) Сайт, где учат программировать

### 2. В чём разница между терминалом и CLI?

- [ ] A) Это одно и то же, разницы нет
- [ ] B) CLI — это кнопки, а терминал — команды
- [ ] C) Терминал — окно, а CLI — способ управлять программой текстовыми командами внутри него
- [ ] D) CLI — это база данных, а терминал — браузер

### 3. Путь (path) в компьютере — это:

- [ ] A) Адрес файла или папки в дереве компьютера, как адрес квартиры
- [ ] B) Программа для рисования
- [ ] C) Скорость интернет-соединения
- [ ] D) Название любого файла

### 4. Зависимости (dependencies) в проекте — это:

- [ ] A) Файлы, которые нужно удалить
- [ ] B) Готовые куски чужого кода (библиотеки), без которых проект не работает
- [ ] C) Ошибки в программе
- [ ] D) Настройки в .env-файле

### 5. Файл package.json по аналогии — это:

- [ ] A) Записка с секретными настройками у входа
- [ ] B) Список покупок: какие зависимости и каких версий нужны проекту
- [ ] C) Готовое блюдо
- [ ] D) Адресная книга сотрудников

### 6. Переменные окружения (environment variables) — это:

- [ ] A) Кнопки в браузере
- [ ] B) Комментарии в коде
- [ ] C) Настройки «за кадром», которые код читает извне: API-ключ, режим dev/prod
- [ ] D) Названия папок проекта

### 7. Причина фразы «у меня работало, а у тебя нет» НЕ является:

- [ ] A) Разные версии зависимостей
- [ ] B) На одном компьютере зависимости установлены, на другом — нет
- [ ] C) Разные переменные окружения (например, API-ключ)
- [ ] D) На одном из компьютеров не установлен браузер вообще

### 8. Правильное место для API-ключа:

- [ ] A) Вшить прямо в код, чтобы было удобно
- [ ] B) Отправить в чат агенту вместе с проектом
- [ ] C) В переменную окружения / .env-файл, который не показывают никому
- [ ] D) В название папки проекта

---

## Ключ ответов

1. **C** — Терминал — окно для команд, а не «хакерская» программа
2. **C** — Терминал = окно, CLI = способ общения командами
3. **A** — Путь — это адрес в дереве файлов
4. **B** — Зависимости — чужой готовый код, «купленные продукты»
5. **B** — package.json — список покупок с версиями
6. **C** — Настройки за кадром: ключи, режимы, адреса
7. **D** — Проблемы обычно в версиях, зависимостях или настройках, а не в отсутствии браузера
8. **C** — Секреты живут в переменных окружения / .env, а не в коде или чате
