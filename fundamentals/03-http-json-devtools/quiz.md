# Quiz — Ф3. HTTP, JSON, DevTools: как работает API

**Порог:** ≥80% (7 из 8 правильных)

---

## Вопросы

### 1. HTTP по аналогии урока — это:

- [ ] A) Язык почтовых открыток между браузером и сервером: запрос → ответ
- [ ] B) Программа для рисования сайтов
- [ ] C) Язык программирования для бекенда
- [ ] D) Название базы данных

### 2. Метод GET означает:

- [ ] A) «Отправь и создай новое»
- [ ] B) «Удали»
- [ ] C) «Замени полностью»
- [ ] D) «Покажи мне данные»

### 3. Что означает статус-код 404?

- [ ] A) У сервера пожар, всё сломалось
- [ ] B) Запрос прошёл успешно
- [ ] C) Страница или ресурс не найдены — адрес не существует
- [ ] D) Нужно подождать и повторить

### 4. Разница между 4xx и 5xx:

- [ ] A) 4xx — сервер сломался сам, 5xx — ты ошиблась в адресе
- [ ] B) Нет никакой разницы
- [ ] C) 4xx — ошибка на твоей стороне (не тот адрес, нет доступа), 5xx — поломка на стороне сервера
- [ ] D) 5xx означает успех, а 4xx — перенаправление

### 5. JSON — это:

- [ ] A) Язык программирования, на котором пишут сайты
- [ ] B) Стандартный формат передачи данных: пары «поле: значение», анкета, понятная обеим сторонам
- [ ] C) Тип картинки для сайтов
- [ ] D) Программа для тестирования API

### 6. DevTools → вкладка Network показывает:

- [ ] A) Историю посещённых сайтов
- [ ] B) Пароли, сохранённые в браузере
- [ ] C) Настройки интернета
- [ ] D) Журнал всех запросов сайта: адреса, методы, статус-коды и ответы

### 7. Endpoint (окошко API) — это:

- [ ] A) Кнопка на клавиатуре
- [ ] B) Главная страница любого сайта
- [ ] C) Конкретный адрес API для конкретного дела: /users, /orders
- [ ] D) Название браузера

### 8. Почему нельзя копировать «как есть» весь запрос из DevTools в сторонний чекер или чат?

- [ ] A) Потому что запросы слишком длинные и некрасивые
- [ ] B) Потому что чекеры не понимают английский
- [ ] C) Потому что в заголовках запроса могут быть видны твои токены доступа — ключи к аккаунту
- [ ] D) Потому что это запрещено законом о копирайте

---

## Ключ ответов

1. **A** — HTTP — правила обмена «открытками»: всегда запрос и ответ
2. **D** — GET — «покажи», чтение данных
3. **C** — 404: ресурс не найден, не тот адрес
4. **C** — 4xx — твоя ошибка, 5xx — их поломка
5. **B** — JSON — стандартная «анкета» с полями и значениями
6. **D** — Network — рентген: все запросы, статусы и ответы
7. **C** — Endpoint — конкретный адрес «окошка» API
8. **C** — В запросах видны токены — делиться ими опасно
