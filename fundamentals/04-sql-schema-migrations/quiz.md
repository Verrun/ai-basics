# Quiz — Ф4. SQL, связи в базе данных, схемы и миграции

**Порог:** ≥80% (7 из 8 правильных)

---

## Вопросы

### 1. В аналогии с библиотекой **таблица** — это:

- [ ] A) Одно поле на карточке
- [ ] B) Уникальный номер читательского билета
- [ ] C) Стеллаж с карточками одного типа
- [ ] D) Журнал ремонтов библиотеки

### 2. Что делает команда SQL `SELECT`?

- [ ] A) Добавляет новую запись в таблицу
- [ ] B) Удаляет таблицу целиком
- [ ] C) Показывает записи, которые подходят под условие
- [ ] D) Меняет план здания склада

### 3. **Primary key (первичный ключ)** — это:

- [ ] A) Пароль администратора базы данных
- [ ] B) Ссылка из одной таблицы на запись в другой
- [ ] C) Первое поле любой таблицы
- [ ] D) Уникальный номер записи, по которому её можно найти однозначно

### 4. Связь **«один-ко-многим»** лучше всего описывает пара:

- [ ] A) Пользователь ↔ его настройки профиля
- [ ] B) Клиент ↔ его заказы
- [ ] C) Студент ↔ курсы, на которые он записан
- [ ] D) Человек ↔ его паспорт

### 5. **Схема (schema)** базы данных — это:

- [ ] A) Секретный документ с паролями
- [ ] B) Журнал всех запросов к базе
- [ ] C) Копия базы на случай поломки
- [ ] D) План склада: какие таблицы есть, какие у них колонки и как они связаны

### 6. Зачем нужны **миграции (migrations)**?

- [ ] A) Чтобы ускорить работу SQL-запросов
- [ ] B) Чтобы данные автоматически копировались в облако
- [ ] C) Чтобы изменения схемы делались пронумерованными шагами, одинаково на всех копиях базы
- [ ] D) Чтобы удалять старые таблицы без подтверждения

### 7. Что произойдёт, если выполнить `DELETE FROM клиенты;` без условия WHERE?

- [ ] A) Удалится только последняя добавленная запись
- [ ] B) Ничего — команда не сработает без WHERE
- [ ] C) Удалятся все записи из таблицы
- [ ] D) Удалится только таблица, данные сохранятся

### 8. Почему нельзя просто «поменять схему руками в проде»?

- [ ] A) Потому что прод работает только ночью
- [ ] B) Потому что ручная правка — это не миграция: копии базы разойдутся, а данные можно потерять безвозвратно
- [ ] C) Потому что SQL запрещает менять схему
- [ ] D) Никаких причин — это нормальная практика

---

## Ключ ответов

1. **C** — Таблица это стеллаж с карточками одного типа (строки = карточки, колонки = поля).
2. **C** — SELECT просит показать записи, подходящие под условие (INSERT добавляет, UPDATE меняет, DELETE удаляет).
3. **D** — Primary key — уникальный номер записи; ссылка на другую таблицу — это foreign key.
4. **B** — У одного клиента много заказов; человек-паспорт и пользователь-настройки — один-к-одному, студенты-курсы — многие-ко-многим.
5. **D** — Схема это договорённость о структуре склада: таблицы, колонки, связи.
6. **C** — Миграции пронумерованы и повторяемы, поэтому все копии базы меняются одинаково и в одном порядке.
7. **C** — Без WHERE условие читается как «все записи» — таблица окажется пустой.
8. **B** — Ручная правка не записана в «журнал ремонтов»: копии разойдутся, а откатиться будет нечем.
