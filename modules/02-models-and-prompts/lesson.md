# М2. Модели и промпты

## За 2 минуты

Разные модели — для разных задач. Хороший промпт = **роль → задача → контекст → формат → ограничения**.

---

## Объяснение

### Зачем несколько моделей

Одна модель не лучшая для всего. **Prompt (промпт)** — твоё ТЗ для AI; **модель** — исполнитель с разными сильными сторонами.

| Модель | Сильная сторона | Когда выбирать |
|--------|-----------------|----------------|
| **ChatGPT** | Универсал, экосистема | Повседневные задачи, картинки, голос |
| **Claude** | Длинные тексты, анализ | Документы, редактура, рассуждения |
| **Gemini** | Google-сервисы | Docs, Gmail, поиск Google |
| **Perplexity** | Ответ + ссылки | Факты, исследования, новости |
| **GLM** (Zhipu) | Код, китайский контекст | Альтернатива западным моделям |
| **Kimi** (Moonshot) | Очень длинный контекст | Большие PDF, длинные переписки |
| **Grok** (xAI) | Актуальность, X/Twitter | Тренды, новости из соцсетей |

### Структура промпта

**Термин:** prompt — текстовая инструкция для AI.  
**Аналогия:** *техническое задание для фрилансера.*

Пять частей:

1. **Роль** — «Ты SMM-менеджер кофейни»
2. **Задача** — «Напиши пост для Instagram»
3. **Контекст** — «Кофейня в центре, целевая аудитория — офисные работники»
4. **Формат** — «100 слов, 3 абзаца, эмодзи умеренно»
5. **Ограничения** — «Без слова "уникальный", тон дружелюбный»

**Слабый промпт:** «Напиши пост про кофе»

**Сильный промпт:** «Ты SMM-менеджер. Напиши пост для Instagram про кофейню в бизнес-центре. 100 слов, дружелюбный тон, призыв зайти на обед. Без клише.»

### Сравнение моделей на практике

Один и тот же вопрос разным моделям может дать разные ответы:
- Perplexity добавит ссылки
- Claude даст развёрнутый анализ
- ChatGPT — универсальный черновик

---

## Практика

1. Открой [exercises/prompt-template.md](../../exercises/prompt-template.md).
2. Перепиши **слабый промпт** по шаблону (выбери свою тему).
3. Задай **один и тот же вопрос** двум моделям (например, ChatGPT и Perplexity).
4. Сравни: длина, стиль, есть ли ссылки, что точнее.

---

## Частые ошибки

1. **Слишком короткий промпт** — AI додумывает сам, результат непредсказуем.
2. **Не указать формат** — получишь простыню текста вместо поста.
3. **Выбирать одну модель для всего** — Perplexity лучше для фактов, Claude — для длинных текстов.
