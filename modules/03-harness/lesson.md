# М3. Harness (обёртка вокруг AI)

## За 2 минуты

**Harness** — это не промпт. Это «коробка» вокруг модели: инструменты, правила, лимиты. Без harness AI только отвечает текстом; с harness — действует.

---

## Объяснение

### Что такое Harness

**Термин:** harness — обёртка вокруг LLM.  
**Аналогия:** *коробка с инструментами и правилами вокруг AI.*

Состав:
- **Модель** — «мозг» (LLM)
- **Инструменты** — файлы, браузер, поиск (через MCP — в следующем модуле)
- **Правила** — что можно и нельзя
- **Лимиты** — сколько попыток, куда не лезть
- **Лог** — что AI делал:а (для проверки)

### Примеры без кода

| Harness | Что даёт |
|---------|----------|
| AI + калькулятор | Точные цифры, не «примерно 100» |
| AI + доступ к файлам | Читает твой документ, отвечает по нему |
| AI только читает | Не может ничего удалить или изменить |
| AI + лимит 3 попытки | Не крутится бесконечно |

### Harness vs промпт

| | Промпт | Harness |
|--|--------|---------|
| Что это | Одна инструкция | Система вокруг модели |
| Аналогия | Задание на сегодня | Должностная инструкция + инструменты |
| Пример | «Напиши пост» | Агент + правила (AGENTS.md) + MCP |

### OpenCode: агент · правила · навыки

**Агент** — AI сам выбирает действия (создать файл, поискать, прочитать). Режимы: **build** — делает, **plan** — только планирует.  
**Правила (Rules)** — файлы `AGENTS.md` в проекте и глобально: постоянные инструкции.  
**Навыки (Skills)** — готовые инструкции для задач (SKILL.md).

Вместе это harness в OpenCode.

## Практика

1. Открой [exercises/harness-checklist.md](../../exercises/harness-checklist.md).
2. Выбери **реальную задачу** (например: «подготовить презентацию», «исследовать конкурентов»).
3. Заполни чеклист: инструменты, правила, лимиты.
4. *(Опционально)* Добавь в OpenCode одно простое правило: строку «Всегда отвечай на русском» в файл `AGENTS.md` в проекте — как его создать, подскажет агент.

---

## Частые ошибки

1. **Путать промпт и harness** — промпт разовый, harness постоянный.
2. **Давать AI все права** — без лимитов и песочницы.
3. **Не логировать действия** — потом непонятно, откуда взялся результат.
