# М4. MCP и плагины OpenCode

## За 2 минуты

**MCP** — «разъём», через который AI подключается к сервисам. **Plugin** — надстройка, ставится одной командой. Для research, design и знаний — свой набор MCP.

---

## Объяснение

### MCP (Model Context Protocol)

**Термин:** MCP — стандарт подключения AI к внешним сервисам.  
**Аналогия:** *USB-порт — один формат, много устройств.*

Без MCP AI только генерирует текст. С MCP — ищет в интернете, читает Figma, работает с Obsidian.

### Plugin vs MCP

| | MCP | Plugin |
|--|-----|--------|
| Что | Протокол (разъём) | Надстройка, ставится командой |
| Аналогия | Кабель | Прибор с кабелем |
| Настройка | `opencode mcp add` / `opencode.jsonc` | команда установки плагина |

Часто plugin уже включает MCP.

### CLI — командная строка

**Термин:** CLI (Command Line Interface) — интерфейс, где программу запускают **текстовыми командами**, а не кликами.  
**Аналогия:** *голосовая команда «Alexa, включи музыку» — короткая фраза вместо десяти нажатий.*

**Термин:** терминал — приложение, куда вводят команды; OpenCode сам живёт внутри терминала.  
**Аналогия:** *окно переписки с компьютером — ты или AI пишете строку, система отвечает текстом.*

| Способ | Как выглядит | Пример |
|--------|--------------|--------|
| **Конфиг** | `opencode mcp add` / `opencode.jsonc` | Подключить Firecrawl MCP |
| **CLI** (команды) | Терминал: `npm install -g firecrawl-cli` | Установить Firecrawl CLI |
| **MCP + Agent** | Чат: «найди статьи через Firecrawl» | AI сам вызывает CLI или API |

**Зачем CLI в курсе AI:**
- многие MCP-серверы внутри запускают CLI-утилиты;
- Agent в OpenCode часто выполняет `git`, `curl`, `gh` в терминале;
- `/loop` и automations тоже опираются на фоновые команды.

**Тебе не нужно** учить команды наизусть. Нужно понимать:
1. Agent **может** открыть терминал и что-то установить — это нормально.
2. Если просят «подтверди команду» — читай, *что* делает (скачать, установить, отправить в git), а не каждый флаг.
3. Опасные команды (удалить всё, force push) — отменяй или спрашивай AI «объясни, что делает эта команда».

**Примеры из курса:**
- `Firecrawl CLI` — поиск и скрейп из терминала (Context7 подскажет установку).
- `git push` — отправить материалы курса на GitHub (делает Agent по запросу).
- `uvx document-converter-mcp` — запуск MarkItDown MCP (прописывается в конфиге один раз).

### Research: поиск в интернете

| Инструмент | Зачем | Приоритет |
|------------|-------|-----------|
| **Firecrawl** | Поиск, скрейп, crawl | Обязательно |
| **Tavily** | Быстрый web search | Рекомендуется |
| **Browser MCP** | AI читает страницу сам | Рекомендуется |
| **MarkItDown** | PDF/Word → текст для AI | Рекомендуется |
| **Context7** | Актуальная документация | Рекомендуется |
| **Exa** | Семантический поиск | По желанию |

*Perplexity — отдельный сервис (браузер), не MCP.*

### Design: прототипы и вёрстка

| Инструмент | Зачем | Приоритет |
|------------|-------|-----------|
| **Figma** | Макеты и слайды из OpenCode | Обязательно |
| **Chrome DevTools** | AI-инспектор живой страницы | Рекомендуется |
| **MagicPath** | Быстрые UI-макеты | По желанию |

### Obsidian-стек: знания и планы

| Инструмент | Зачем |
|------------|-------|
| **Obsidian MCP** | AI читает/пишет заметки в vault |
| **Plannotator** | Review планов → сохранение в Obsidian |
| **MarkItDown** | Документы в базу знаний |

**Связка:** Plannotator → план в Obsidian → MarkItDown добавляет PDF → AI ищет по vault.

### Установка (упрощённо)

1. **Плагины:** ставятся командой в терминале (например, `npx oh-my-opencode-slim@latest install` — оркестрация из М11)
2. **MCP вручную:** `opencode mcp add <имя> -- npx -y <пакет>` или секция `"mcp"` в конфиге `opencode.jsonc`
3. **Plannotator + Obsidian:** Plannotator → Settings → Obsidian Integration → выбрать vault
4. **Проверка:** спроси агента «какие MCP подключены?»

### Безопасность

- Не подключай MCP с доступом к почте/банку без нужды
- API-ключи — только в настройках, не в промптах
- Читай, какие права запрашивает plugin

## Частые ошибки

1. **Ставить все MCP сразу** — начни с минимума, добавляй по задаче.
2. **Путать Perplexity и Firecrawl MCP** — Perplexity отдельный сайт; Firecrawl — внутри OpenCode.
3. **Не проверять подключение** — после установки задай тестовую задачу.
4. **Бояться терминала** — CLI не значит «учить Linux». Agent выполняет команды; ты проверяешь результат.
