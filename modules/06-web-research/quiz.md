## Вопросы

### 1. Perplexity отличается от Google тем, что:

- [ ] A) Не работает в браузере
- [ ] B) Даёт ответ и ссылки сразу
- [ ] C) Только для программистов

- [ ] A) Рисования картинок
- [ ] B) Поиска и сбора информации с сайтов
- [ ] C) Редактирования видео
- [ ] D) Создания музыки

- [ ] A) Нужно прочитать PDF для AI
- [ ] B) Нужно опубликовать пост
- [ ] C) Нужно смонтировать видео
- [ ] D) Нужно нарисовать логотип

### 4. Fact-check включает:

- [ ] A) Только один источник
- [ ] B) 2 независимых источника, дата, автор
- [ ] C) Только доверие AI
- [ ] D) Только Wikipedia

### 5. Оцени достоверность: «AI говорит: 87% пользователей предпочитают продукт X, источник не указан»

- [ ] A) Полностью достоверно
- [ ] B) Недостаточно — нет источника, цифра может быть выдумана
- [ ] C) Достоверно, если AI уверен
- [ ] D) Не важно

### 6. Где искать open-source проекты для research?

- [ ] A) TikTok
- [ ] B) GitHub
- [ ] C) Spotify
- [ ] D) Netflix

---

## Ключ ответов

1. **B** — Ответ + ссылки
2. **B** — Поиск и сбор с сайтов
3. **A** — PDF для AI
4. **B** — 2 источника, дата, автор
5. **B** — Нет источника = галлюцинация
6. **B** — GitHub
