## Вопросы

### 1. RAG простыми словами — это когда модель:

- [ ] A) Рисует картинки по тексту
- [ ] B) Сначала ищет куски в твоих документах, потом отвечает по ним
- [ ] C) Только ищет в Google
- [ ] D) Заменяет fact-check

### 2. Чем RAG отличается от поиска в интернете (М6)?

- [ ] A) Ничем — это одно и то же
- [ ] B) RAG опирается на *твои* материалы; веб-поиск — на сайты снаружи
- [ ] C) RAG работает только офлайн без компьютера
- [ ] D) Веб-поиск всегда точнее RAG

### 3. Зачем режут документы на chunks?

- [ ] A) Чтобы красивее выглядело в PDF
- [ ] B) Чтобы в запрос попадали короткие релевантные куски, а не вся энциклопедия
- [ ] C) Чтобы удалить все факты
- [ ] D) Чтобы модель забыла контекст

### 4. Embedding — это:

- [ ] A) Пароль от базы знаний
- [ ] B) «Смысловой отпечаток» текста — числа, по которым ищут похожее
- [ ] C) Название кнопки в Figma
- [ ] D) Тип галлюцинации

### 5. Когда разумнее просто прикрепить файл в чат, а не строить RAG?

- [ ] A) Всегда нужен RAG
- [ ] B) Один короткий документ (несколько страниц)
- [ ] C) Только если файл на английском
- [ ] D) Никогда нельзя прикреплять файлы

### 6. Главный риск RAG:

- [ ] A) Модель всегда молчит
- [ ] B) Если нужный кусок не нашёлся (или документы плохие), ответ всё равно может быть выдуман
- [ ] C) RAG запрещает цитировать источники
- [ ] D) Работает только без вопроса

### 7. e5-small в RAG нужна, чтобы:

- [ ] A) Писать длинные ответы вместо ChatGPT
- [ ] B) Локально строить смысловые отпечатки и искать похожие куски текста
- [ ] C) Рисовать слайды в Figma
- [ ] D) Заменять fact-check ссылками из Google

### 8. Golden set для RAG собирают, чтобы:

- [ ] A) Красиво назвать папку с PDF
- [ ] B) Иметь эталон «вопрос → нужные куски» и ловить падение качества поиска
- [ ] C) Обучить модель рисовать
- [ ] D) Заменить все документы одним промптом

---

## Ключ ответов

1. **B** — Сначала найти в своих документах, потом ответить
2. **B** — Свои материалы vs интернет
3. **B** — Короткие релевантные куски
4. **B** — Смысловой отпечаток
5. **B** — Короткий один файл — достаточно чата
6. **B** — Нет куска / плохие доки → возможна выдумка
7. **B** — Эмбеддинги и смысловой поиск (не чат)
8. **B** — Эталон для проверки retrieval
