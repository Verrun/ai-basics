# М7. Поиск информации в интернете

## За 2 минуты

Perplexity — ответ + ссылки. MCP (Firecrawl, MarkItDown, Tavily) — AI ищет сам в OpenCode; Tavily — поисковик, сделанный специально под AI. Всегда **fact-check**: 2 источника, дата, автор.

*Интернет — снаружи. Поиск по своим файлам (RAG) — в [М8](../08-rag/lesson.md).*

---

## Объяснение

### Perplexity vs Google

| | Google | Perplexity |
|--|--------|------------|
| Результат | Список ссылок | Ответ + ссылки |
| Кто читает | Ты | AI + ты проверяешь |
| Когда лучше | Найти конкретный сайт | Быстрый research с выводами |

Perplexity — **отдельный сервис** (сайт/приложение), не MCP в OpenCode.

### MCP для research

| Инструмент | Задача |
|------------|--------|
| **Firecrawl** | «Найди и собери с N сайтов» |
| **MarkItDown** | PDF/статья → текст для AI |
| **Browser MCP** | AI открывает и читает страницу |
| **Tavily / Exa** | Быстрый или семантический поиск |

### Tavily: поиск, заточенный под AI

**Термин:** [Tavily](https://www.tavily.com) — поисковая система, созданная специально для AI: вместо «стопки ссылок» возвращает чистый структурированный результат — выжимку с выдержками и источниками, которую удобно отдать модели.  
**Аналогия:** *Google — библиотекарь, который вываливает стопку книг и уходит; Tavily — ассистент, который приносит готовую выписку со списком источников.*

| | Perplexity | Firecrawl | Tavily |
|--|-----------|-----------|--------|
| Для кого | Для тебя (чат-сервис) | Для агента | Для агента |
| Что делает | Отвечает + даёт ссылки | Заходит на конкретные сайты и собирает текст | Ищет по всему интернету, возвращает выжимку с источниками |
| Как подключить | Сайт / приложение | MCP | MCP или API |

**Как подключить в OpenCode:** попроси агента «добавь Tavily MCP». Нужен бесплатный API-ключ с [tavily.com](https://www.tavily.com) — тариф Researcher даёт ~1000 запросов в месяц, для учёбы хватает.

**Важно:** Tavily ускоряет **поиск**, но fact-check не отменяет — источники всё равно проверяешь ты (чеклист выше).

### GitHub-проекты

Open-source инструменты для research — список в [github-tools-list.md](../../exercises/github-tools-list.md).

- `awesome ai search`

**На что смотреть:** stars, дата последнего коммита, понятный README.

### Fact-check (проверка фактов)

**Fact-check** — сверка утверждений AI с независимыми источниками.

Чеклист:
- [ ] 2 независимых источника
- [ ] Дата публикации актуальна
- [ ] Есть автор / организация
- [ ] Факты совпадают между источниками

## Практика

1. Открой [exercises/research-brief.md](../../exercises/research-brief.md).
2. Выбери одну тему.
3. Сравни **3 инструмента:** Perplexity + Firecrawl MCP + Browser MCP.
4. Заполни таблицу «источник / дата / вывод».
5. Проверь минимум 2 ссылки вручную.

---

## Частые ошибки

1. **Верить AI без проверки** — особенно цифрам и датам.
2. **Один источник** — нужно минимум два независимых.
3. **Игнорировать дату** — статья 2019 может быть неактуальна.
