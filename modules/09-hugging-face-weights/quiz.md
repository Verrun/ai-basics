# Quiz — М9. Веса моделей и Hugging Face

**Порог:** ≥80% (7 из 8 правильных)

---

## Вопросы

### 1. Hugging Face — это:

- [ ] A) Чат-бот, который отвечает на вопросы
- [ ] B) Крупнейшая библиотека моделей: карточки, файлы весов и демо
- [ ] C) Социальная сеть для маркетологов
- [ ] D) Замена ChatGPT для повседневных задач

### 2. Веса модели — это:

- [ ] A) Пароль для запуска модели
- [ ] B) Миллиарды чисел в файлах — всё, что модель выучила при обучении
- [ ] C) Список промптов для модели
- [ ] D) Тарифный план на Hugging Face

### 3. Архитектура без весов — это:

- [ ] A) Полноценная модель, готовая к работе
- [ ] B) «Пустой череп»: план есть, выученных знаний нет
- [ ] C) Модель, которая лучше экономит память
- [ ] D) Обязательное условие для чата

### 4. Закрытыми весами пользуются так:

- [ ] A) Скачивают файлы с Hugging Face
- [ ] B) Только через чат или API компании (GPT, Claude, Gemini)
- [ ] C) Печатают веса вручную из документации
- [ ] D) Дообучают модель под себя

### 5. У каких моделей веса открытые?

- [ ] A) GPT, Claude, Gemini
- [ ] B) Llama, Qwen, GLM
- [ ] C) Только у эмбеддингов, у остальных закрытые
- [ ] D) Все модели имеют открытые веса по умолчанию

### 6. «Открытые веса = можно всё» — верно ли?

- [ ] A) Да, открытые значит без ограничений
- [ ] B) Нет: лицензия может ограничивать коммерцию — читай карточку модели
- [ ] C) Да, если модель больше 7B
- [ ] D) Ограничения есть только у закрытых весов

### 7. Зачем вайбкодеру локальная модель с открытыми весами?

- [ ] A) Чтобы документы и личные тексты не покидали ноутбук
- [ ] B) Она всегда умнее закрытых моделей
- [ ] C) Чтобы не нужен был интернет-браузер
- [ ] D) Локальные модели работают без электричества

### 8. Что обязательно смотреть в карточке модели на HF?

- [ ] A) Только аватар автора
- [ ] B) Тип модели, размер, лицензию и автора
- [ ] C) Количество комментариев
- [ ] D) Ничего — модели все одинаковые

---

## Ключ ответов

1. **B** — Полка моделей: карточки, веса, демо
2. **B** — Выученный «мозг» в виде файлов с числами
3. **B** — Архитектура = план, веса = выученный опыт
4. **B** — Только чат/API, файлы не отдают
5. **B** — Открытые: Llama, Qwen, GLM
6. **B** — Лицензия в карточке может ставить ограничения
7. **A** — Приватность: данные остаются у тебя
8. **B** — Тип, размер, лицензия, автор
