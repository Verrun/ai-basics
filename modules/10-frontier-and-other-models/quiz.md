# Quiz — М10. Frontier и другие модели

**Порог:** ≥80% (7 из 8 правильных)

---

## Вопросы

### 1. Frontier-модель — это:

- [ ] A) Модель с открытыми весами
- [ ] B) Модель на «переднем крае» возможностей на текущий момент
- [ ] C) Самая дешёвая модель сервиса
- [ ] D) Модель, которая работает только офлайн

### 2. Frontier ≠ «закрытые веса», потому что:

- [ ] A) Все frontier-модели имеют открытые веса
- [ ] B) На переднем крае бывают и закрытые (GPT, Claude), и открытые (DeepSeek, Qwen) модели
- [ ] C) Весов вообще не существует
- [ ] D) Закрытые модели всегда слабее открытых

### 3. В лестнице моделей специализированные модели — это:

- [ ] A) Автокран: одна задача, но отлично (эмбеддинги, картинки, аудио)
- [ ] B) Просто «плохие» чат-модели
- [ ] C) Всегда большие и дорогие
- [ ] D) Замена frontier во всех задачах

### 4. Типовая рутина (письма, резюме, переводы) разумнее всего на:

- [ ] A) Всегда frontier — так надёжнее
- [ ] B) Средней или маленькой модели — дешевле и быстрее
- [ ] C) Эмбеддингах из М9
- [ ] D) Только локальных моделях без интернета

### 5. Роутинг («auto» в сервисах) — это когда:

- [ ] A) Модель сама пишет за тебя письма
- [ ] B) Сервис сам подбирает модель: простое — быстрой дешёвой, сложное — frontier
- [ ] C) Ты всегда платишь за самую дорогую модель
- [ ] D) Интернет отключается

### 6. Как правильнее относиться к бенчмаркам-лидербордам?

- [ ] A) Таблица №1 в зачёте = лучший выбор для любой задачи
- [ ] B) Читать критично и свежо: зачёт синтетический — проверяй своим мини-тестом на своих задачах
- [ ] C) Игнорировать полностью, они бессмысленны
- [ ] D) Верить только таблицам годовалой давности

### 7. Локальная маленькая модель может быть лучше frontier, когда:

- [ ] A) Документы чувствительные и не должны покидать ноутбук
- [ ] B) Нужно самое глубокое рассуждение
- [ ] C) Нужен очень длинный контекст
- [ ] D) Локальные всегда лучше

### 8. Почему не стоит заучивать «список лучших моделей»?

- [ ] A) Его всё равно проверяют на границе
- [ ] B) Фронтир двигается: состав переднего края меняется каждые пару месяцев, навык — уметь проверять
- [ ] C) Списки моделей запрещены лицензиями
- [ ] D) Все модели одинаковые

---

## Ключ ответов

1. **B** — Класс «переднего края» на момент времени
2. **B** — Сила модели и открытость весов — два разных измерения
3. **A** — Одна задача, но отлично (автокран)
4. **B** — Рутина — средние/маленькие, frontier — точечно
5. **B** — Диспетчер: раскидывает задачи по лестнице моделей
6. **B** — Свежий зачёт + свой мини-тест
7. **A** — Приватность важнее силы
8. **B** — Знай лестницу классов, умей проверять
