---

## Вопросы

### 1. Оркестрация AI-агентов — это:

- [ ] A) Один агент делает всё подряд быстрее
- [ ] B) Координатор делит задачу между агентами-специалистами и сводит результаты
- [ ] C) Способ сжать промпт
- [ ] D) Автоматическая загрузка моделей с Hugging Face

### 2. oh-my-opencode-slim — это:

- [ ] A) Новая языковая модель
- [ ] B) Плагин оркестрации для OpenCode с готовой командой агентов
- [ ] C) Редактор кода от OpenAI
- [ ] D) Облачное хранилище файлов

### 3. Explorer в команде — это:

- [ ] A) Агент на frontier-модели для сложных багов
- [ ] B) Быстрая дешёвая разведка: находит нужные куски кода
- [ ] C) Дизайнер интерфейсов
- [ ] D) Менеджер, который пишет ТЗ

### 4. Зачем Council опрашивает несколько моделей?

- [ ] A) Чтобы потратить больше денег
- [ ] B) Получить несколько мнений и свести их в один проверенный вердикт
- [ ] C) Чтобы модели обучались друг у друга
- [ ] D) Это украшение интерфейса

### 5. Почему у разных агентов разные модели?

- [ ] A) Исторически сложилось
- [ ] B) Это лестница М10 на уровне задачи: рутину — дёшево и быстро, сложное — frontier
- [ ] C) Все агенты обязаны работать на одной модели
- [ ] D) Дешёвые модели не умеют искать по коду

### 6. `/interview` → `/implement` — это про:

- [ ] A) Агент интервьюирует тебя, собирает требования, потом реализует по спецификации
- [ ] B) Загрузку интервью с YouTube
- [ ] C) Обучение модели на твоих данных
- [ ] D) Проверку паролей

### 7. Кто финально отвечает за качество результата оркестрации?

- [ ] A) Orchestrator — он всё проверил:а
- [ ] B) Oracle — он самый умный
- [ ] C) Ты: diff глазами и запуск проекта своими руками (Ф9)
- [ ] D) Никто — команда сама всё гарантирует

### 8. Для какой задачи команда агентов оправдана?

- [ ] A) Поменять цвет одной кнопки
- [ ] B) Ответить на один простой вопрос
- [ ] C) Задача из нескольких частей: исследовать, спланировать, сделать, отревьюить
- [ ] D) Написать одно короткое письмо

---

## Ключ ответов

1. **B** — Прораб + бригада вместо одного универсального AI
2. **B** — Плагин оркестрации для OpenCode
3. **B** — Разведка на дешёвой быстрой модели
4. **B** — Консилиум: несколько мнений → один вердикт
5. **B** — Специализация агентов = роутинг моделей по сложности
6. **A** — Требования собраны до кода (дисциплина ТЗ из М2)
7. **C** — Проверка остаётся на тебе
8. **C** — Многочастные задачи; для мелочи хватит одного агента
